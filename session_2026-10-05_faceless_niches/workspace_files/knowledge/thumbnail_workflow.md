# Thumbnail Generation Workflow (ENFORCED — Non-Negotiable)

**Added:** 2026-09-21
**Applies to:** ALL channels, ALL videos, ANY time thumbnails are discussed.

## Rule: Outlier-First Thumbnail Design

Whenever Priyanshu asks to create, design, or generate a thumbnail for ANY video topic, this workflow is MANDATORY. Do NOT skip steps. Do NOT jump straight to generating a thumbnail.

### Step 1: Find Outlier Videos (vidIQ)
- Use vidIQ's outlier search to find all outlier videos on the SAME TOPIC (not same title — same topic).
- Cast a wide net: include different title variations, angles, and phrasings of the topic.
- Collect at least 5-10 outlier videos.

### Step 2: Extract & Analyze Their Thumbnails (vidIQ)
- Use vidIQ's `similar_thumbnails` or manual extraction to pull every outlier video's thumbnail.
- For EACH thumbnail, reverse-engineer and document:
  - **Composition:** Layout, focal point, rule of thirds, whitespace usage.
  - **Colors:** Dominant palette, contrast strategy, background color.
  - **Text:** What text is on the thumbnail (if any), font style, size, placement.
  - **Faces/Emotions:** Any faces shown, what emotion, eye direction.
  - **Objects/Props:** Key visual elements, scale, positioning.
  - **Curiosity trigger:** What makes a viewer NEED to click? What's the visual hook?
  - **What's deliberately hidden/cropped:** What is NOT shown that creates curiosity?

### Step 3: Compile the Reverse-Engineering Data
- Create a structured summary of ALL analyzed thumbnails.
- Identify common patterns across the top performers.
- Identify what's DIFFERENT about the #1 outlier vs the rest.
- Note any anti-patterns (things all outlier thumbnails avoid).

### Step 4: Generate Thumbnail Concepts
- Use the compiled data to generate 3-5 thumbnail concepts that:
  - Incorporate the winning patterns from outlier analysis.
  - Fix weaknesses found in existing outlier thumbnails.
  - Are BETTER than every thumbnail analyzed — not copies, improvements.
- Each concept must explain WHY it would outperform the existing outliers.

### Step 5: Generate the Thumbnail
- Use image generation (Nano Banana, ChatGPT, or vidIQ's generate_thumbnail) to create the final thumbnail.
- The generation prompt must reference specific insights from the outlier analysis.

## Why This Workflow Exists
- Priyanshu's baseline for any thumbnail is: "At minimum, better than every outlier's thumbnail on this topic."
- Skipping the research step means guessing. Guessing = average thumbnails. Average = no clicks.
- This workflow guarantees every thumbnail is data-informed, not vibes-informed.
