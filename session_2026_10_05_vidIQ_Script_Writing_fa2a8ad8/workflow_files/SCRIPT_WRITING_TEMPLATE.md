# Script Writing Template

Use this for any faceless YouTube script, in any niche. Fill in Part A first, then follow Parts B to F in order. Part G is the check you run before the script is handed over.

This file holds no example scripts on purpose. Don't copy wording from anywhere, this file included.

## Part B: What testing has shown (method level)

| Method | Result | Use it? |
|---|---|---|
| vidIQ Scriptwriter with "Match Reference Video" | Rewrote the reference in new words: same hook, same order, same examples. There's no instruction field, so it can't be told not to copy. Weakest result. | **No**, for anything built on a reference |
| vidIQ AI Coach, one prompt asking for analysis + structure + full script | Better hook and order, but it fell back on the reference's facts and some near-copied sentences. The quality was spread too thin across three jobs. | Only as a quick draft |
| AI Coach one-shot, then a "fix only these paragraphs" prompt in the same chat | The targeted fixes worked. They also added a new factual distortion. | Yes for surgical edits, but fact-check the fixes |
| AI Coach multi-step: (1) analysis only → (2) skeleton + first half → (3) second half | Best result. It researched new sources, built real open loops, a real tone shift and a stronger voice. It still had structural and fact problems that needed an audit. | **Yes. The current best vidIQ method** |
| Writing it ourselves from vidIQ MCP data (2–3 transcripts + comments) | Not tested yet | Pending |

Why multi-step wins: analysis done separately forces the model to understand the mechanics first. Writing in halves keeps quality even across the script. Leaving room to research brings in material the references don't have.

## Part C: Originality rules

1. Take **techniques** from references: pacing, re-hook rhythm, transition style, voice traits. Never take their **facts, examples, hook, section order or wording**.
2. Never build a "must include" list out of a reference's own content. That makes a reworded copy. Build it from your own research.
3. Use 2–3 references from different channels. One reference gives you a copy, several give you patterns.
4. At least a third of the facts should come from sources none of the references used.
5. Change the formula from video to video: hook type, counting device, where the dark turn and humor go, the closing style. YouTube's "inauthentic content" policy (July 2025) demonetizes template-like, mass-produced content. AI help is allowed. Sameness is the risk.
6. Compare the finished script against every reference transcript. Rewrite any sentence that matches a reference in meaning **and** rhythm.

---

## Part D: Structure rules

**Hook (first 30–60 seconds)**
7. Open on something concrete and strange, like an object, place, finding or moment. Don't use the hook a reference already used.
8. Plant one real open loop that only pays off in the final quarter.
9. No disclaimers or "scientists disagree" in the hook. Save that for the payoff.
10. The hook has to deliver on the title's promise quickly.

**Body**
11. No separate "introduction" after the hook. Go straight into the first section.
12. No spoken table of contents.
13. Order sections by stakes or urgency, not by date. Each section fixes what the one before it couldn't.
14. Problem-door transitions: end every section by naming what it couldn't solve, and that becomes the next section's opener.
15. If you promise a count ("N reasons / N jobs"), keep **every** section inside it, or make the last item the biggest. The frame must not finish before the video does, or viewers will feel it's over and leave.
16. Re-hook roughly every 35–55 seconds and rotate the type: mystery lead-in, myth correction, stakes raise, authority line, emotional hammer, tone shift. Never use the same type twice in a row.
17. Plant a second open loop at the midpoint so the back half has its own pull.
18. Dark turn at about 60–70% of runtime: one section with a real, sourced human cost.
19. Humor goes right after the dark turn, so it plays as relief. It should be a real change in tone lasting several sentences, not a passing wink.
20. Every section carries at least one specific, checkable detail: a named place, date, study or person.

**Ending**
21. End on a reframe that ties the topic to something the viewer feels today.
22. No standalone "like and subscribe."
23. Never send viewers to the comments mid-video. It sends them away. If there's an ask, it goes in the last line.

## Part E: Voice rules (how to sound human)

24. Write it to be heard, not read. Short sentences, mostly under 12 words. Use fragments for rhythm.
25. Talk to the viewer directly as "you." Make them part of the story, not someone watching it.
26. Be firm where the evidence is solid. Hedge once, right at the contested claim ("one study suggests," "might"). Never keep announcing your own honesty.
27. Tie every number to a picture the viewer already knows. Never dump numbers in a row.
28. Add a dry aside about every two minutes, so it doesn't feel like a lecture.
29. Watch the medium. It's a video, so never write "reading this" or "as you can see" for things that aren't shown.
30. Cut on sight:
    - The "That's not X. That's Y." construction more than once per script
    - Piled-up "Here's the thing / Here's what" openers
    - "genuinely," "truly," "incredibly," "game-changer," "testament to," "delve," "tapestry," "in conclusion"
    - Em dashes in most sentences
    - A three-item list in every paragraph
    - Closing lines that restate the paragraph
    - A narrator who praises their own honesty more than once
31. Read it out loud. Split any sentence you can't say in one breath.

---

## Part F: Fact rules

32. Check every name, date, number and quote before voiceover. Citations an AI put in the script still get checked.
33. Label the strength of each claim: finding stated firmly, interpretation as an interpretation, myth called a myth.
34. Never invent a quote, or describe what a historical person "wrote" without the source text.
35. Never turn a range or margin of error into a single round figure.
36. Keep evidence periods straight. Later or ethnographic examples must be labelled as such, not presented as evidence for an earlier era.
37. No invented "back-of-envelope" numbers unless the math is shown and sourced.
38. Keep a proof list next to the script: claim → source → checked yes/no.

Hand over one final script plus this table filled in. The person producing the video shouldn't have to re-read drafts to judge quality.

## Prompting notes (vidIQ AI Coach)

- One YouTube video can be attached per chat through "+ → Add from YouTube." Links pasted as text aren't read.
- Text files (transcripts) can be attached through "Attach image or file."
- About 10 credits per message regardless of length, so put full context in every prompt.
- Prompt order: analysis only → skeleton + first half → second half → targeted fix prompt.
- Every prompt should include the goal, the context, the specific failures to avoid, and a request for a proof list.
- Tell it to research new sources. Don't hand it a reference's facts as requirements.
- Fix prompts should name each problem and the fix, and end with "rewrite only the affected paragraphs."
