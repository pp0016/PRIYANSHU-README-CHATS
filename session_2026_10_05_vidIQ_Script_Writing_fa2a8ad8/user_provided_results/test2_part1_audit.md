### What's Still Weak (Surgery Targets)

1. **The humor beat is too mild.** The reference has a full 58-second comedy rant that acts as a pattern interrupt. The one-shot has two gentle jokes ("sounds made up until you try it" / "freezer before the plug-in kind"). For a faceless channel competing for attention, the tonal contrast needs to be sharper. Doesn't have to be crude like the reference, but needs to be a real break in the register.

2. **The closer echoes the reference's concept.** "Pressing a button for heat" and "thermostat" — the reference uses "tapping a button for heat." Same idea, same phrasing direction. This needs a different conceptual angle for the closer.

3. **The cooperation/dark-turn section (line 94) is compressed.** Cannibalism gets one vague sentence ("The record shows it") without a specific site or detail. Either commit to it with evidence or cut the hint — a half-mention is weaker than both alternatives.

4. **Yaghan section is thin.** Could use one more specific detail (e.g., Darwin's account of seeing them, specific temperature data for Tierra del Fuego).
