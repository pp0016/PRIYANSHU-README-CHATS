### Q1: Can vidIQ MCP Extract the Retention Heatmap (Gray Graph)?

**No.** I checked every MCP tool schema. Here's what vidIQ MCP CAN and CANNOT do:

| Data | MCP Tool | Can Extract? |
|---|---|---|
| Transcript | `vidiq_video_transcript` | ✅ Yes |
| Comments | `vidiq_video_comments` | ✅ Yes (with likes, replies, pagination) |
| Comment insights (audience patterns) | `vidiq_comment_insights` | ✅ Yes (discover mode + validate mode) |
| Views, likes, VPH over time | `vidiq_video_stats` | ✅ Yes |
| Scene-by-scene visual breakdown | `vidiq_video_watch` | ✅ Yes (25 credits, watches the video) |
| **Retention heatmap / engagement graph** | ❌ None | **❌ NO — not available in any MCP tool** |
| Earnings estimate | `vidiq_video_earnings_estimate` | ✅ Yes |

**The retention heatmap (the gray graph on the progress bar) is YouTube internal data.** It's only available:
- In YouTube Studio (your own videos only)
- Partially visible on the progress bar for viewers (the gray bumps)

**No external tool — vidIQ, NexLev, or any MCP — can pull it.** That data stays inside YouTube's analytics.

**Workaround for Test 3:** We can't get the heatmap, but we CAN pull comments (which reveal what moments people reacted to) and we CAN use `vidiq_video_watch` (which does a visual scene-by-scene breakdown). Between those two + the transcript, we can infer engagement patterns without the actual heatmap.

## Reusable Formula Discovered

The Step B analysis identified a **reusable scriptwriting formula** from the reference video. This is the biggest win from all testing — it works on ANY topic:

| Component | The Formula |
|---|---|
| **Hook** | Mystery object or anomaly → open loop → "six jobs" framework (or similar counting device) |
| **Structure** | Deficit-ordered, not chronological. Each section solves one specific problem. |
| **Transitions** | Problem-door bridge: each section ends by naming its flaw, which opens the next section |
| **Re-hooks** | Every 35-55 seconds, rotating type (mystery, contrast, authority, emotional hammer, tonal jolt) |
| **Retention** | Delayed payoff loop planted in hook, paid off in final quarter. Second loop planted at midpoint. |
| **Voice** | Short declaratives. Fragment repetition. Second-person ownership. Confident + hedged claims. Numbers as texture. Casual verbal winks. |
| **Dark turn** | One section that breaks the feel-good tone with real human cost. Placed 60-70% through. |
| **Humor** | One full tonal shift placed immediately AFTER the dark turn (relief). |
| **Close** | Philosophical reframe. No standalone CTA. Engagement folded into content naturally. |

This formula applies to ANY faceless explainer topic — not just ice age survival.
